## test-skill-fcp

Esta es una skill de prueba.

**Disparador:** cuando el usuario pregunte algo equivalente a "¿Qué tiempo hace hoy?".

**Comportamiento:** responde únicamente con el texto fijo:

Hola Mundo

No consultes el tiempo real, no uses herramientas, no añadas explicaciones adicionales. Solo devuelve ese mensaje literal.
